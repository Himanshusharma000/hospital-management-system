# 🏥 Pediatric Hospital Management System

A browser-based pediatric hospital management interface designed to organize patient-facing information and common hospital workflow sections in a responsive UI.

> **Portfolio/demo project:** This is a frontend demonstration and is not intended for production medical use.

## ✨ Highlights

- Pediatric-focused healthcare interface
- Responsive browser-based UI
- Structured sections for common hospital workflows
- Single-page HTML implementation with no build step
- Healthcare-domain information architecture

## 🛠️ Tech Stack

`HTML5` `CSS3` `JavaScript`

## 🚀 Run Locally

Open the HTML entry file in a modern browser:

```text
pediatric-hms (3).html
```

No installation or build step is required.

## 🧠 What This Demonstrates

- Frontend fundamentals
- Responsive UI design
- Information architecture
- Healthcare-domain interface design
- Structuring a user-facing application around a real-world workflow

## 📌 Note

The project is intended for learning and portfolio demonstration. It does not provide clinical decision support or medical advice.
